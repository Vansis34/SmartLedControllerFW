- Пункт получает `[x]` только после сборки и соответствующей проверки.
- Проверка на реальном устройстве отмечается отдельно от проверки сборкой.

## Журнал

- 2026-07-22 — backlog создан по согласованному плану; начат этап фундамента.
- 2026-07-23 — завершена F-04: legacy PUT endpoints переведены с `sscanf`
  на cJSON, добавлены лимит body 1024 байта и полный receive-loop, команды
  проходят через `AppState_Apply()`. PlatformIO-сборка успешна.
- 2026-07-23 — завершена F-01: разводка GPIO, параметры PWM, тайминги,
  значения по умолчанию и ресурсные лимиты собраны в `app_config.h`.
  Разрядность LEDC и максимальный duty связаны формулой; `_Static_assert`
  проверяет основные инварианты конфигурации при сборке.
- 2026-07-23 — завершена F-02: `AppState` хранит единое состояние под mutex,
  применяет patch через copy/validate/commit и выдаёт стабильные snapshots.
  Смысловые поля сравниваются без `memcmp` по padding-байтам, а список
  подписчиков копируется под mutex перед вызовом callbacks.
- 2026-07-23 — завершена F-03: custom partition table для 2 MiB flash
  содержит NVS 24 KiB, PHY 4 KiB и factory app 1984 KiB без OTA. PlatformIO и
  `sdkconfig` используют один `partitions.csv`; бинарная таблица декодирована
  и проверена штатным инструментом ESP-IDF.
- 2026-07-23 — завершена F-05: PlatformIO pre-build hook автоматически
  создаёт детерминированный `index.html.gz`. Архив атомарно заменяется только
  при изменении HTML; повторная сборка оставляет файл и его timestamp без
  изменений.
- 2026-07-23 — завершена L-01: `LED_Init()` запускает `led_worker`, подписывает
  короткий listener на `AppState` и отправляет стартовое task notification.
  Worker при каждом уведомлении получает последний независимый snapshot через
  `AppState_Get()`.
- 2026-07-23 — завершена L-02: единая функция расчёта целей явно описывает
  четыре режима. Синхронный, противофазный и неполный противофазный режимы
  используют независимые fade/pause профили из snapshot; неизвестный режим
  безопасно выбирает нулевые duty. PlatformIO-сборка успешна.
- 2026-07-23 — завершена L-03: времена хранятся в миллисекундах и переводятся
  в ticks только через `pdMS_TO_TICKS`; новый state заменяет движение от
  текущего duty. LED worker перечитывает последнюю revision из `AppState`,
  поэтому callbacks, пришедшие не по порядку, не откатывают PWM.
- 2026-07-24 — LED signaling упрощён: очередь без используемого payload
  заменена прямым task notification. Изменения могут объединяться, а worker
  всегда читает последнее подтверждённое состояние из `AppState`.
- 2026-07-24 — завершена L-04: `Button_Init()` запускается из `app_main`,
  GPIO13 опрашивается с debounce, а короткое нажатие после отпускания меняет
  только `AppState.power`. Детектор long press сохранён, но настоящий reset
  вынесен в L-04b после N-03.
- 2026-07-24 — временное STA-подключение использует compile-time
  `CONFIG_EXAMPLE_WIFI_SSID/PASSWORD` через неизменённый
  `protocol_examples_common`. Handlers регистрируются до подключения, HTTP
  server запускается после получения IP.
- 2026-07-24 — завершена W-03 для legacy API: WEB проверяет HTTP status,
  перечитывает подтверждённый `/status` после команд и polling-ом раз в секунду
  отражает изменения от физической кнопки. Неподдерживаемый speed скрыт.
- 2026-07-24 — для стендовой диагностики включён compile-time уровень DEBUG:
  добавлены `ESP_LOGD` успешного WEB JSON, валидации AppState candidate,
  старта, завершения и замены fade. PlatformIO-сборка успешна.
